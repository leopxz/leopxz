## Projetos em destaque

### Automação e IA
**[Banco Jangada – Assistente financeiro com MCP](https://github.com/leopxz/banco-jangada):** Chat financeiro que usa o protocolo MCP (Model Context Protocol) conectado às APIs de Open Finance Pluggy e Plaid (Sandbox), simulando o app de um banco fictício. Usa apenas dados fictícios. [Ver app publicado](https://banco-jangada.lovable.app).<br>
**[Detecção de fraude em transações de cartão](https://github.com/leopxz/NOME-DO-REPOSITORIO-DE-FRAUDE):** Notebook em Python (Google Colab) que analisa transações de cartão e treina modelos de Machine Learning para identificar fraudes.<br>
**[Desafio Criativo – Planejamento de automação com n8n](https://github.com/leopxz/Desafio_Criativo):** Prompt estruturado para planejar fluxos de automação no n8n, definindo gatilhos, integrações e etapas do processo.<br>
**[IA – Reconhecimento das mãos](https://github.com/leopxz/IA-reconhecimento-das-maos):** Visão computacional que controla o volume do computador por gestos das mãos, com OpenCV e MediaPipe em detecção em tempo real.<br>
