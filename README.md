## Projetos em Destaque
**[PowerBi Relatórios](https://github.com/leopxz/PowerBi_Relatorios):** Relatórios interativos e visualizações de dados usando Power BI, focados em transformar dados brutos em insights acionáveis.<br>
**[Projeto de Data Science](https://github.com/leopxz/ProjetoDataScience):** Projetos de análise de dados e modelos preditivos. Utilizo bibliotecas como Pandas, Scikit-learn e Matplotlib para construir análises completas e precisas.<br>
**[Projeto Lafepe](https://github.com/leopxz/ProjetoLafepe):** Projeto acadêmico focado na automação de processos para a empresa Lafepe, com o objetivo de otimizar fluxos de trabalho e melhorar a eficiência.<br>
**[Projeto de Machine Learning](https://github.com/leopxz/projeto-machine-learning):** Um projeto de predição de vendas, utilizando técnicas de Machine Learning para analisar dados históricos e prever tendências futuras de mercado.<br>
**[Landing Page para Freelance](https://github.com/DeepLore7/Landing-Page_EvertonTenorio):** Landing page profissional desenvolvida para um cliente freelance, usando HTML, CSS e JavaScript.<br>
**[IA - Reconhecimento das mãos](https://github.com/leopxz/IA-reconhecimento-das-maos):** Um projeto de visão computacional que permite controlar o volume do computador com base no reconhecimento de gestos das mãos. Utilizei OpenCV e MediaPipe para a detecção em tempo real, aprimorando minhas habilidades em automação e detecção de gestos.<br>
